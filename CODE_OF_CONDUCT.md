# Code of Conduct

## Our pledge

We want MULEGUARD to be a welcoming, respectful, and constructive project for contributors of all experience levels and backgrounds.

Everyone participating in project spaces is expected to act professionally, communicate with empathy, and focus criticism on ideas and code rather than people.

## Expected behaviour

- Be respectful and constructive when reviewing code or discussing ideas.
- Welcome questions and beginner contributions.
- Explain disagreements with evidence and without personal attacks.
- Accept feedback gracefully and assume good intent while addressing impact.
- Respect privacy and avoid sharing personal information or confidential data.
- Keep examples, tests, issue reports, and demonstrations synthetic; do not post real customer or financial data.
- Follow the project's security reporting process for vulnerabilities.

## Unacceptable behaviour

- Harassment, discrimination, threats, or targeted personal attacks.
- Trolling, insults, or deliberately disruptive conduct.
- Publishing another person's private information without permission.
- Sharing credentials, customer data, or other confidential material.
- Testing against systems or data without authorization.
- Knowingly submitting malicious code or disguising unsafe behaviour.

## Maintainer responsibilities

Project maintainers may edit, hide, or remove content that violates this code and may temporarily or permanently restrict participation when needed to protect the community. When practical, maintainers will explain moderation decisions.

## Reporting

Report conduct concerns privately to the repository maintainer through their GitHub profile. Avoid raising sensitive matters in public issues. Include relevant links and a concise description, and do not share unnecessary personal data.

## Scope

This code applies in project repositories, issues, pull requests, discussions, and other spaces where someone is representing or participating in the project.

## Attribution

This policy is adapted from the Contributor Covenant principles. It is intended to be a practical community standard for this project.
